# Contributing to MailGester

Issues and pull requests are welcome.

## Before you start

For anything larger than a small fix, open an issue first so the direction can be agreed before you spend time on it.

Contributions that the maintainer accepts are distributed under the [PolyForm Noncommercial License 1.0.0](LICENSE), together with the grant above.

## Practical rules

- Keep one change per pull request.
- Match the existing code style.
- Do not add dependencies without discussing it first.
- Do not commit secrets, real mail data or real webhook URLs.
